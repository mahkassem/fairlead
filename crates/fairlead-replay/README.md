# fairlead-replay

Replay of failed CI runs for Fairlead: fetch, extract, attribute and report.

This crate is internal to [Fairlead](https://github.com/mahkassem/fairlead) and
is published only so that `cargo install fairlead` can build. Its API has no
semver promise: any release may change it. Install the CLI instead:

```sh
cargo install fairlead
```
