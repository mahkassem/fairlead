# Roadmap

| Milestone | Delivers |
|---|---|
| K0 | Workspace, CI, release pipeline, installers, docs |
| K1 | Config and the test plan (import graph, test classes, CI plan), replay and the benchmarks |
| K2 | Guard rules, Claude Code hooks, git hooks, event log |
| K3 | Receipts, workflows, done gates, the change brief ([#45](https://github.com/mahkassem/fairlead/issues/45)), CI report, Codex hooks |
| K4 | Memory, search, skills and skill routing ([#43](https://github.com/mahkassem/fairlead/issues/43)), import |
| K5 | MCP server, trackers, headless runner, token sources |
| K6 | Blueprints, readiness score, insights, 1.0 |

Alongside the milestones, [any stack, any framework, any layout](https://github.com/mahkassem/fairlead/issues/47) brings more languages (PHP first, then Python and Go), Vue, Svelte and Astro components, framework packs such as Laravel's, coverage maps, and folders of several repositories.

Each milestone is an issue on GitHub with its exit criteria.
