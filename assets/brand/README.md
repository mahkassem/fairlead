# Fairlead brand

The official Fairlead mark is the Guardrail Monogram: an F made of two dark
rails with a green guided path between them, after the fitting on a boat that
keeps a line running true. Use these files as they are; don't redraw, recolor
or stretch them. The wordmark is outlined, so no font is needed.

## Colors

| Name | Hex | Use |
| --- | --- | --- |
| Dark | `#0B1618` | The rails and wordmark on light backgrounds, and dark backgrounds |
| Guide | `#008F67` | The guided path on light backgrounds |
| Guide on dark | `#00AE7B` | The guided path on dark backgrounds |
| White | `#FFFFFF` | The rails and wordmark on dark backgrounds |
| Deep guide | `#087C5C` | The darker tone of the two-tone green icon |
| Black | `#000000` | The monochrome black logo |

## Use

- Pick the light or dark version by the background, never both on one.
- Keep clear space around the mark of at least the height of the green guide.
- Use the icon alone below 120 px wide; the wordmark stops reading there.
- Use the monochrome versions only where color isn't available.

## Where it's used

- The README header (light and dark versions).
- The documentation site's title bar and favicon.
- The GitHub App that publishes the benchmarks, and the repository's social preview.
